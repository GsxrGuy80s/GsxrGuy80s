# Building Local-First AI Systems

I'm building tools that move AI workloads off rented cloud infrastructure and onto hardware you control.

## Current Projects

### Pocket Node

Android app for running GGUF models locally on-device.

- Local model loading and inference
- Model Hub for GGUF download/import
- OpenAI-compatible Edge API path for trusted LAN use
- Current public prerelease: [Pocket Node v0.1.0-rc2](https://github.com/Zero-Cloud-Tax/pocket-node-releases/releases/tag/v0.1.0-rc2)

### Sovereign Brain

A self-hosted AI control plane for routing tasks across local machines, mobile nodes, and automation workflows.

### Zero Cloud Tax

A practical framework for reducing recurring cloud spend by moving workloads to local-first infrastructure.

## What I Build
